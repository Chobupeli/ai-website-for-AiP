# AI — интерактивный гид

Одностраничный сайт про искусственный интеллект: история, технологии,
интерактивная нейросеть на canvas и мини-квиз «ИИ или человек?».

## 🔗 Демо
https://chobupeli.github.io/ai-website/

## 🛠 Стек
- HTML5, CSS3 (Grid, Flexbox, анимации)
- Vanilla JavaScript + Canvas API
- Шрифты Google Fonts

## 📦 Запуск локально
Просто открой `index.html` в браузере.
